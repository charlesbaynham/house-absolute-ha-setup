# Claude Code adapter

This is a Home Assistant configuration repository with an agent memory workspace layered on it. The
contract (`AGENTS.md`), this workspace's own rules (`WORKSPACE.md`: git flow, live-API rules, how to
work on the config) and the memory digest are imported so they are present from the first turn.
`AGENTS.md`, `WORKSPACE.md` and `memory/digest.md` must all exist or the imports fail.
